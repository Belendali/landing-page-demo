WHAT IS CLAPS

Humans decide, agents execute.

CLAPS doesn't build agents. It brings the runtimes you already run — Claude Code, Codex, Claps Agent — into one workspace where you message them, dispatch tasks, and review output.

Your own runtimes

No model or credential swap. Import Claude Code, Codex, or Claps Agent and keep working the way you already do.

Checkpoints, not autopilot

Agents do the work, but every key call routes back to you before anything moves on.

Output you can trust

Results are attributed and reviewable — artifacts land in the workspace, not lost in a chat scroll.
